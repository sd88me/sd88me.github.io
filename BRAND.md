# sd88me brand notes

**Positioning:** Precision for the ineffable. The engineer's rigour, the dancefloor's trance.
**Primary line:** Circuit-true instruments for deep states.

## The name: keep sd88me
Keep it as the brand, the handle and the manufacturer string (`sd88me - VST - Name`). Don't rename.
- It is already on every plugin folder, in the Open MPC catalog, Discord and GitHub.
- It is unique: searches for it only find you.
- Cryptic names suit the underground (AFX, µ-Ziq, Ø, Autechre).
- `sd88.me` is a domain hack of the handle. No DNS records existed when checked on 2026-11-26. Register it.

Three readings, used across the site:
1. **s·d·88·me**: the signature (initials, birth year, me).
2. **sedate me**: the state the instruments are for.
3. **8 + 8**: an octave (2:1) drawn on an oscilloscope is a figure 8. One for the circuit, one for the cosmos.

If a second name is ever needed, use it as a product line under sd88me: **sd88me Editions** (paid line), Double Eight, or Octave Works.

## Logo
- Wordmark: single-stroke lowercase. Each 8 is a 2:1 Lissajous figure (x = sin 2t, y = sin t), in phosphor; the letters are in ink.
- Mark: the 2:1 figure inside a round scope bezel with graticule. Used for the favicon and avatar.
- Sigils: every plugin gets a Lissajous figure from its own ratio (Acid-303 3:1, Reverbicon 224 5:4, Machinemodule 4:3 and so on).
- Always lowercase. Clear space = the height of one 8. Minimum 72 px wide.
